🎮 Tic Tac Toe (Rolling Edition)

A digital twist on the classic Tic Tac Toe game, built using HTML, CSS, and JavaScript — the game never ends in a draw!

🔗 Live Demo
https://gwkavya.github.io/Digital-Tic-Tac-Toe-game-/

✨ Features

• Classic 3x3 Tic Tac Toe grid
• Rolling marks system — each player can only  • have 3 marks on the board at a time, so there's no draw
• Winner detection across all 8 win patterns
• Reset and New Game buttons
• Clean, responsive UI with gradient background

🛠️ Tech Stack
• HTML5
• CSS3
• JavaScript

📌 About

This project is a twist on the traditional Tic Tac Toe game. Instead of stopping when the board fills up, each player is limited to 3 marks on the board — placing a 4th mark removes the oldest one automatically. It helped me strengthen my understanding of DOM manipulation, array-based state management, and event handling in JavaScript.
