Tic Tac Toe (Rolling Edition)
🎮 Play Live
A twist on the classic Tic Tac Toe game — instead of stopping when the board fills up, this version keeps the game going forever until someone actually wins!
How it's different
In normal Tic Tac Toe, the game can end in a draw when the board fills up. Here, each player can only have 3 marks on the board at a time. As soon as a player places their 4th mark, their oldest mark disappears automatically. This keeps the board dynamic and the game continues endlessly until someone forms a winning line.
Features
Classic 3x3 Tic Tac Toe grid
Rolling marks system (max 3 marks per player)
Winner detection across all 8 win patterns
Reset and New Game buttons
Clean, responsive UI with gradient background
